II. HƯỚNG DẪN CÀI ĐẶT TỪNG BƯỚC VÀO BLOGGER
================================================================================

【CÁCH A: CÀI ĐẶT NGUYÊN BẢN THEME XML VÀO BLOGGER (KHUYÊN DÙNG)】
- Bước 1: Tải file "blogger-theme.xml" về máy tính hoặc điện thoại.
- Bước 2: Mở trình duyệt web, vào trang https://blogger.com và đăng nhập.
- Bước 3: Ở menu bên trái, nhấp vào "Chủ đề" (Theme).
- Bước 4: Nhấp vào dấu 3 chấm dọc bên cạnh chữ "TÙY CHỈNH" (Customize) -> Chọn "Khôi phục" (Restore).
- Bước 5: Nhấp "Tải lên" (Upload) -> Chọn file "blogger-theme.xml" vừa tải.
- Bước 6: Đợi 3 giây để Blogger áp dụng giao diện mới. Truy cập trang blog của bạn để ngắm nhìn thành quả!

【CÁCH B: DÙNG TIỆN ÍCH TIỆN LỢI TRÊN BỐ CỤC (GADGET HTML/JAVASCRIPT)】
- Nếu bạn đã có sẵn theme Blogger và chỉ muốn thêm khung giới thiệu "better and better", 4 lá thư tình và bộ công cụ thử mật khẩu:
- Bước 1: Vào Blogger -> Mục "Bố cục" (Layout).
- Bước 2: Tìm vị trí bạn muốn đặt (ví dụ: ngay dưới Header hoặc trên đầu Thân trang) -> Nhấp "Thêm tiện ích" (Add a Gadget).
- Bước 3: Chọn loại tiện ích "HTML/JavaScript".
- Bước 4: Mở file "blogger-template.html", bấm Ctrl+A để chọn tất cả rồi copy.
- Bước 5: Dán vào ô Nội dung của tiện ích HTML/JavaScript trong Blogger -> Nhấp "Lưu".
